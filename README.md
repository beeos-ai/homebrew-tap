# BeeOS Homebrew Tap

Homebrew formulae for [BeeOS](https://beeos.ai) tools.

## Install

```bash
brew install beeos-ai/tap/bma
```

`bma` is the BMA (BeeOS Managed Agents) command line and BYO executor, released from
[beeos-ai/bma-executor-sdk](https://github.com/beeos-ai/bma-executor-sdk).

## Update

```bash
brew upgrade bma
```
